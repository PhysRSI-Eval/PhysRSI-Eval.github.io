Physical RSI reference and benchmark-predicted profiles for six VLMs. The five displayed axes follow the original A1–A5 order clockwise from the top: Prior knowledge, Efficiency, Success, Cost, and Improvement. These are user-specified display labels; the underlying metrics remain A1 initial performance, A2 gain timing, A3 high-window score, A4 quota savings, and A5 failure recovery. Cost retains the A4 quota-savings definition: a larger value means more budget saved. All radii use the same linear 0–1 scale, with grid rings at intervals of 0.25; numerical labels are omitted. In individual comparisons, solid slate-blue lines with filled circles show Actual working-reference values; dashed terracotta lines with open diamonds show Predicted values. Model overlays use a separate consistent model-color and marker legend; solid/filled and dashed/open still distinguish reference from prediction. Faint alternating neutral bands mark radial scale intervals and do not encode uncertainty. The reference uses 18 tasks through K17 and three Context repeats per task for K0. Per-axis methods were selected post hoc among 98 configurations using six-model leave-one-model-out errors; each prediction was trained on the other five models. For GPT-5.6 Sol, the supplied fitted pack_objects_into_box continuation at K7–K17 is retained as the working reference: its scores affect A2/A3 and its non-success assumptions affect A4/A5. No uncertainty intervals, significance claims, new fitting, normalization, or smoothing are introduced in this visual revision.
